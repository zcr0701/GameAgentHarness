# GameAgentHarness

面向游戏引擎的**受约束大模型 Agent-Harness**：把「生成—选择分离 + 可组合安全原语」范式落地为一套可在 Unity 内置入本地大模型的决策系统。

## 核心思路

- **AI 不直接发命令，命令由原语构造保证安全** —— 模型只在合法操作 shell 内自由组合。
- **有限原语 × 受限组合语法 × 组合校验器** ⇒ 有限合法组合制造无限行为。
- **OpenJev 决策头（decision-native）**：在候选组合上打分选优，它决定「选哪个」，不决定「能否执行」。
- 安全始终由**设计 + 校验器（纯规则，零 LLM 依赖）**保证，不依赖模型对规则的自觉。
