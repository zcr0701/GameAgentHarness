# 地脉程序编辑器与运行器

更新时间：2026-09-24。M1 当前实现方案。本系统让玩家编排工程脉冲对地形与敌人的作用；名称、模块和效果按本作“地脉工程”世界观独立设计。界面默认简体中文，可在设置切为英语。

## 使用方式

按 `Tab` 打开编辑模式，按顺序添加、重排或移除模块；右侧模块和预设可滚动查看。可载入基础脉冲、无尽回响、地平线破城、掘地震波四个预设。关闭编辑器后按住鼠标左键运行程序，按 `X` 停止所有仍在传播的回响链。程序按本地 PlayerPrefs 保存，重开关卡保留排列。

## 语言语义

程序是一串最多 24 个模块的有序指令。修饰模块从左到右累积，遇到 `EMIT` 时生成一组切割脉冲，然后清空该组修饰；没有后续 `EMIT` 的修饰不会产生效果。编辑器添加修饰模块时，默认插入在最后一个 `EMIT` 前，方便立即试验；随后可用上下移动改变顺序。多个 `EMIT` 可在一次触发中产生不同的脉冲组，能量作为一次事务预先结算，不会只执行半个程序。

| 模块 | 对下一次 `EMIT` 的影响 |
| --- | --- |
| `FORK` | 脉冲数量乘 3，最多 9 发，形成扇形 |
| `EXPAND` | 作用半径乘 1.9，最多 24 Unity 单位 |
| `AMPLIFY` | 对敌伤害乘 2，最多 64 |
| `BLAST` | 命中产生范围震爆；大范围破坏分帧执行 |
| `ECHO` | 有 `BLAST` 时在震爆完成后调度下一次回响 |
| `RECYCLE` | 有效命中或震爆回收能量 |
| `DRILL` | 脉冲钻穿可破坏岩土与沙层，遇敌人停止；半径也会扩大钻孔宽度 |
| `FUSE` | 延后下一次命中爆破；每个模块增加 0.55 秒，最多 3.3 秒。单独使用也会把命中变成小型定时爆破 |
| `IMPULSE` | 直接命中或范围爆破时击退敌人；每个模块增加冲击力，最多 25 |
| `EMIT` | 提交当前脉冲组并重置修饰状态 |

默认储能上限 100，缓慢自然回复。普通脉冲命中敌人/可破坏地形时，`RECYCLE` 返还能量；震爆时返还 12，后续每次 `ECHO` 消耗 4。因此 `BLAST → ECHO → RECYCLE → EMIT` 可形成**持续自供能**的震爆链，直到玩家按 `X`、修改程序、死亡或关卡结束。这里“无限”指可持续运行时间，不把无限次工作塞进同一帧。

`EXPAND` 叠加 6 次后的半径达到上限 24，可覆盖大部分关卡；`AMPLIFY` 叠加 6 次达到 64 点伤害；`FORK` 可让一次 `EMIT` 形成多个起点。`Horizon Breaker` 预设把这些模块与持续回响放在同一程序里。默认不对玩家造成自身震爆伤害，以便先验证创造性玩法与性能；这一规则可在后续平衡时再评估。

`DRILL + RECYCLE` 每枚钻脉最多回收一次能量，避免逐格挖掘造成无限能量刷取；钻脉线段沿格子采样并只通过 `GridTerrain` 修改材料。

新增机制设计为不同的组合维度：

| 组合 | 产生的打法 |
| --- | --- |
| `FORK + DRILL + EXPAND + BLAST` | 多方向钻开更宽的通道，在敌人或钻进末端引爆并清理岩土 |
| `DRILL + FUSE + IMPULSE` | 脉冲穿过地层后触发延时爆破，并将附近敌人震开 |
| `FORK + FUSE + ECHO + RECYCLE` | 多枚定时装药依次回响，构成移动的延时爆破链 |
| `EXPAND + IMPULSE + AMPLIFY` | 大范围高伤震荡，把敌人从洞口或掩体附近推开 |

这些是可叠加修饰而非互斥法术槽。`EMIT` 会分段重置效果，因此一个序列可先发钻脉、再发定时震荡；排列、重复次数和能量预算都会改变结果。新预设“掘地震波”展示钻脉、分叉、延时与扩张的联动。

## 执行与性能边界

```text
玩家编辑的模块序列
  → ProgramCaster 编译/检查能量
  → TerrainPulse 实体碰撞
  → BlastScheduler 事件队列
  → 当帧敌人伤害与视觉反馈
  → 跨帧地形工作队列 → GridTerrain 单格写入
```

- `ProgramCaster` 显式标记每次执行的 token，取消或修改程序时旧弹体、待执行回响和未完成地形工作都会失效。
- `BlastScheduler` 最多保留 64 个待处理/正在处理效果，每帧执行最多 2 个新震爆、检查最多 320 个地形格；积压时暂缓新的施放。效果越大，清理地形可能持续多个物理帧。
- `GridTerrain` 保持地形数据的唯一写入口；边界岩层不可破坏。Tilemap 碰撞在下一物理更新阶段同步。
- 编辑模式暂停游戏时间，关闭/销毁时恢复。视觉效果不承担伤害逻辑。

## 自动检查与待验

玩家进程自动检查覆盖编辑模式暂停/恢复、持续能量回响、取消、24 单位半径与 64 点伤害、钻脉贯穿货架、双延时编译、延时实际等待、震荡施力及大范围分帧完成；构建与检查结果见 `docs/DESIGN.md`。可见窗口截图确认中英文编辑器布局及滚动区域。实机的组合手感、输入体验与平衡仍需人工试玩。

## 与未来 AI 的边界

这是玩家可编辑的本地工具程序。后续 AI 只能在受约束动作候选上选择，不能直接改写该程序或绕过 `GridTerrain`/`BlastScheduler`；若允许 AI 触发工具，也要经纯规则校验与统一队列提交。
