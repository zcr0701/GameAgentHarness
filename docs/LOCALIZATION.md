# 游戏内语言规范

更新时间：2026-09-24。当前游戏只提供**简体中文、英语**两种界面语言。新玩家首次启动默认为简体中文；在游戏右上角或程序编辑器顶部打开“设置”，可立即切换为英语或切回中文。选择保存在本机 `PlayerPrefs`，重开游戏仍生效。

## 实现位置

- `GameLocalization` 持有当前语言、保存选项、中文字体和模块名称。所有运行时玩家可见文案使用 `GameLocalization.T(中文, English)`，两种语言在同一改动中交付。
- `GameSettingsMenu` 管理设置面板与暂停/恢复。设置可从 HUD 或程序编辑器进入，关闭后回到原来的暂停状态。
- `GameHud`、`ProgramEditor` 和 `ProgramCaster` 的状态与预览会读取当前语言，因此切换即时生效；状态不存储已翻译的单语言字符串。
- 当前 Windows 构建从系统字体中选择支持汉字的字体。后续扩展到其他操作系统时，应先打包有再分发许可的中文字体，并复验字体回退。

## 新文案规则

1. 默认以自然中文撰写界面文案，同时提供完整英文。模块名、按钮、提示、结算、错误与动态数值都要覆盖两种语言。
2. 技术日志、Unity 对象名和开发者 Inspector 标题不作为玩家可见文案；如果将来显示到游戏界面，需要先补齐翻译。
3. 修改界面时检查两种语言的实际窗口截图，尤其是较长英文、中文字体、按钮宽度和布局换行。

## 当前验证

Windows 构建无 C# 错误或警告。玩家进程检查了设置暂停/恢复、即时切换与 PlayerPrefs 写入，并在可见窗口截取中英文编辑器、HUD 和英文设置界面。其他分辨率、操作系统与人工按钮体验仍待验证。
