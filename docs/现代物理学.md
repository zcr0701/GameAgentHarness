# 现代物理与材料参数参考

本文汇总游戏基础粒子和破坏机制可参考的公开物理、材料科学数据。目的是让材料取值有可追溯的现实原型，并在设计时正确区分材料密度、流变、划痕硬度和结构破坏强度。这里的实验数值是**参考基准**，不是游戏的无量纲伤害值，也不代表本项目已经实现连续介质或分子动力学求解。

## 使用规则

1. **记录材料原型和试验条件。** “岩石”“木材”“岩浆”都不是单一材料。表中使用花岗岩、巴沙木、石英颗粒、特定流纹质黑曜石和玄武质熔体作为可复查原型；温度、含水率、孔隙、晶体含量与颗粒尺度改变时，数据会变化。
2. **保留 SI 单位和数据来源。** 密度用 kg/m³，动力粘度用 Pa·s，压缩/拉伸强度用 MPa，弹性模量用 GPa。由比重换算得到的密度要注明是近似换算。
3. **不把莫氏硬度当成爆炸阈值。** 莫氏硬度是矿物互相划痕的序数比较；它没有 MPa 单位，也不是抗压强度或抗冲击强度。爆炸破坏要依据加载方式对应的抗压、抗拉、剪切、断裂韧度、冲击应变率和裂纹等因素。
4. **区分材料本体和松散堆积。** 石英晶粒的固体密度约 2650 kg/m³；沙堆因孔隙而具有更低的体积密度。水和熔体的密度也不等于游戏格子的占据率。
5. **区分现实参考量和游戏参数。** `HP/粒`、内聚阈值、壁面附着阈值、离散 tick、粒子尺寸和爆炸伤害都是游戏尺度。除非定义并验证换算关系，不能将其标成实验测得的 N、Pa 或 MPa。

## Noita 粒子/材料物理属性研究

这部分回答“Noita 的粒子有哪些物理属性、分别负责什么”。Noita 官方将其概括为逐像素材料模拟：液体流动、气体上升、沙粒堆积、刚体运动，并辅以简化的化学反应、电与热模拟；GDC 讲座简介确认其技术重点包括扩展 falling-sand 模拟和集成可破坏刚体物理。[Noita 官方 FAQ](https://noitagame.com/)；[GDC 2019 技术讲座简介](https://www.gdcvault.com/play/1025695/contactUs)。

| --- | --- | --- | --- |

**研究材料与限制：** Noita 的完整 C++ 引擎没有在本项目检视的资料中公开。本研究依据官方游戏/讲座介绍、公开构建数据镜像中的 `materials.xml`，以及社区模组字段整理；后两者能帮助核对字段和配置示例，但不是内部算法规范。[公开构建数据镜像](https://github.com/WUOTE/noita-builds-data/blob/main/Builds-data-contents/2432204065973118473/materials.xml)；[社区材料字段表](https://noita.wiki.gg/wiki/Modding%3A_Making_a_custom_material)。例如，现有材料字段中没有找到可直接当作分子间力或壁面附着力的通用字段；`stickyness` 的社区说明是减慢液体内移动，不能直接认作粒子内聚或贴墙力。

完整的字段分组、职责解释与项目设计推导见[《基础粒子.md》的 Noita 材料模型调研](基础粒子.md#noita-材料模型调研)。本项目从中借鉴的是按子系统组织材料行为的架构思路；8×8 细粒子、现实材料参数映射、破坏阈值和黑洞机制仍以本项目自身设计为准，不移植 Noita 代码、素材、材料数值或法术。

## 强度与爆炸破坏模型

### 为什么“硬度”不等于“炸不炸得穿”

材料科学中至少要区分：

- **莫氏划痕硬度**：矿物抵抗被另一材料划伤的相对序数。
- **压痕硬度**：由压头和加载程序决定的局部压入抵抗。
- **抗压强度**：试件在指定边界条件下承受压缩至破坏的应力。
- **抗拉强度与断裂韧度**：裂纹张开或扩展所需的条件；很多脆性材料对拉伸和裂纹尤其敏感。
- **冲击/爆炸破坏**：还受峰值压力、脉冲持续时间、冲量、加载方向、材料几何、约束、已有裂缝及应变率影响。

例如花岗岩可用某个试件的单轴抗压强度作基准，但爆炸在自由表面诱发的拉伸裂纹未必由单轴抗压强度单独决定。黑曜石的 Mohs 5–6 也不能推出它比石英砂更容易或更难被特定爆炸摧毁。

### 项目内可执行的换算边界

当前地形伤害 API 使用离散 `damage` 整数，没有爆压、冲量或接触面积输入。`MaterialParticleCatalog` 对有参考强度的固体暂用 `ceil(参考强度 MPa / 25)` 作为游戏耐久阈值：花岗岩代理以 Sierra White Granite 的较低抗压数据 `178 MPa` 得到 8；深层基底以指定玄武岩试样 `213 MPa` 得到 9；Newberry 黑曜石用围压 5 MPa 下峰值差应力 `381 MPa` 得到 16；12% 含水率巴沙木用顺纹抗压 `14.9 MPa` 得到 1。25 MPa/游戏点是**玩法归一化系数**，只是把有来源的强度量转换成整数阈值；由于测试加载方式、方向和边界条件不同，所得数字不构成严谨的跨材料力学排序，更不表示游戏爆炸造成了对应 MPa 的应力。

要实现定量爆炸物理，仍需将 `PulseSpec.Damage` 映射到材料粒子上的应力/能量，并定义作用面积、脉冲时长、应变率、边界反射和裂纹传播；随后用同一加载模式下的数据标定。木材强度还要处理纹理方向。当前材料阈值仅用于可解释的游戏行为起点，再以隐藏试炼房/自动 smoke 检验实际破坏关系。

黑洞属于明确的超自然规则：它绕开常规硬度/强度判断，把被吸入材料转化为粒子流。它不代表现实黑洞在游戏尺度下的材料作用模拟。

## 与当前代码参数的映射状态

`MaterialParticleCatalog` 的 `Hardness` 是游戏伤害阈值，部分材料阈值按上述归一化参考计算；`MolecularBondNewtons` 和 `WallAdhesionNewtons` 是本项目粒子尺度的离散有效力阈值，不是分子尺度的实验值。水、花岗岩代理、玄武岩基底、黑曜石代理和木材代理的密度采用表中指定试样参考；砂堆密度采用 FHWA 松散干砂单位重换算值。水和岩浆字段粘度选用了所列实测/研究区间；固体、砂与游戏基底的 `ViscosityPascalSeconds` 目前是离散求解器调参，不能解释为这些材料的真实牛顿粘度。当前模拟没有分子尺度键、连续应力场、流体压力求解或爆炸波传播。

项目的 8×8 表示中每个细粒子宽度为 `0.0625 Unity unit`。这类细粒子是体素/材料包，不是现实中单颗石英砂粒子。按 `m = ρV` 将实体密度映射到该体素，会把它当作占据完整体积的连续材料小块；沙堆则需要显式考虑孔隙率或以有效体积密度表示。

在爆炸接口完成强度标定前，当前运行时的硬度、内聚、附着仍须视作游戏调参；已知实验数值只作对照基线。加入新材料时应同时记录：原型、原始来源、试验条件、是否换算、运行时游戏参数及与实验量的差异。
